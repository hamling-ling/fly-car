# 車輪の調整

Arduino Uno Q の App Lab アプリ。十字キーで左右の車輪を動かし、マイコンへ渡す左右の指令をその場で入れる。カメラは使わない。車輪のピンとパルスの式は [remote_control](../remote_control/) と同じ。

`flycar_q` と `remote_control` は止めてから起動する。ポート 7000 を使うので、`color_capture_q` も止める。

## 動かし方

ボード上の置き場所は `~/ArduinoApps/motor_adjust`。PC のリポジトリから置くときは、リポジトリ直下で次を実行する。

```bash
scp -r research/motor_adjust arduino@<ホスト名>.local:~/ArduinoApps/
```

SSH で入って起動する。起動コマンドはシェルに戻る。アプリはそのまま動いている。最初の起動はスケッチをコンパイルする。

```bash
ssh arduino@<ホスト名>.local
arduino-app-cli app start ~/ArduinoApps/motor_adjust/
```

止めるときは、同じ SSH セッションで次を実行する。

```bash
arduino-app-cli app stop ~/ArduinoApps/motor_adjust/
```

`No Colon In First Item Of Depfile` と出たら、スケッチのキャッシュが壊れている。消してから起動し直す。

```bash
rm -rf ~/ArduinoApps/motor_adjust/.cache
arduino-app-cli app start ~/ArduinoApps/motor_adjust/
```

ページはポート 7000。同じ LAN のブラウザで `http://<ホスト名>.local:7000` を開く。

App Lab でこのディレクトリを開いて Run してもよい。Python だけ直したときは、スケッチのキャッシュは消さなくてよい。止めてからコピーし、起動し直す。

## 操作

| 入力 | 車輪 |
| --- | --- |
| ↑ または W | 前進 |
| ↓ または S | 後退 |
| ← または A | その場で左旋回 |
| → または D | その場で右旋回 |
| 前進と左右を同時 | 曲がる側の車輪を止め、反対側だけ進める |
| キーを離す、スペース、画面の「停止」 | 停止 |

右の前進、左の前進、右の後退、左の後退の 4 つが、`setMotorSpeed` に渡す指令そのものである。0〜255 の整数。前進は正、後退は負になって送られる。スライダーと数値は同じ値を示す。欄やスライダーにいるとき、上下キーはその数を 1 変える。欄の外では上下が前進と後退。

はじめの値は、左右が揃っていた前進の右 150・左 149 と、後退の右 91・左 77 である。ページを開き直しても、そのブラウザのタブには最後の値が残る。このアプリは `flycar_q` の指令を書き換えない。

キーを押しているあいだ、ページは 0.2 秒ごとに同じ指令を送り直す。切れてから 0.45 秒で止める。ページを閉じたとき、別の窓へ移ったときも止める。

## 直進の計測

走っている姿では曲がっているかどうかを決めない。車体を出発線に合わせ、「測る」で右の前進と左の前進の数を 0.2〜3 秒（初期値 0.8 秒）だけ送って止める。止まったら、その線から前と後ろが何 mm ずれたかを読む。右が正。間隔は、読んだ 2 点の距離で、初期値は車体の全長 170 mm。

同じ右・左・秒数を 8 回記録する。向きは `atan2(前 − 後ろ, 間隔)` の度。前後が同じだけずれていれば 0。前だけ右なら正で、左輪が速い。平均の 95% 区間が 0 を含めば、その回数では曲がりと区別できない。秒数が違う記録は混ぜない。アプリを止めると記録は消える。ページの下に、コピーできる生の行が出る。

## 車輪

右がピン D3、左がピン D5。指令 -255〜255 を 1000〜2000 µs にする。1500 µs が停止。左モーターの +/- は逆つなぎなので、正の指令は左右とも 1500 µs より長いパルスにする。右はそのパルスで前進し、左は配線が逆なので同じ側のパルスで前へ回る。`setMotorSpeed` の引数は右、左の順。反時計回りだけ広げる倍率は掛けない。
